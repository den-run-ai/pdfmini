# pdfmini
Compress and combine PDFs in a client-side web app. No server uploads - everything runs in your browser.

## Features

- **Compress PDFs** - Reduce file size with adjustable compression levels (low/medium/high)
- **Combine PDFs** - Merge multiple PDFs into one, with drag-and-drop reordering
- **100% Client-side** - Your files never leave your browser
- **No dependencies** - Single HTML file, works offline

## Usage

1. Open `index.html` in a browser
2. Choose **Compress** or **Combine** tab
3. Drop your PDF(s) or click to browse
4. For combine: reorder files by dragging, then click "Combine PDFs"
5. Download the result
